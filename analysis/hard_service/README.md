# Fixed-capacity hard-service diagnostic

This directory preserves the source modification, runner, and authoritative solver outputs for the selected 50% freshwater-demand, 8,000 kg-H2/day condition. The benchmark-derived capacities are fixed, the electrolyzer-feedwater coupling is restored, and both service-shortage variables are constrained to zero for the hard-service solve.

## Reported result

The ordinary fixed-capacity re-evaluation returned `Optimal` with 5,918.31013331 m3/yr of freshwater shortage and 1.81898940355e-12 kg-H2/yr of H2 shortage. The hard-service solve returned `Infeasible`.

The scientific status is taken directly from the raw metric-value summary CSV and CPLEX stderr/stdout files in `results/`. The convenience summary generated by the executed runner is not distributed because its post-processing parser did not recognize the metric-value CSV layout. That parser issue occurred after the solver runs and does not alter the optimization output. `verify_hard_service_result.py` checks the authoritative files.

`EXECUTED_RUNNER_PACKAGE_v1_2.zip` is the standalone package used for the reported diagnostic. The browsable `source/`, `runner/`, and `SOURCE_CHANGE.diff` files are copied from that package.
