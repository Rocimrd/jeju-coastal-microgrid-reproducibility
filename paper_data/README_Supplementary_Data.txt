Supplementary machine-readable data files for release v1.1.0

Data S1: 8,760-hour demand, renewable availability, SMP, and grid-price series.
Data S2: Representative-period selection metrics and ranks.
Data S3: Core 25-condition matched-planning and fixed-capacity re-evaluation summary.
Data S4: All 150 solves from the 0.01% epsilon-optimal RO-capacity audit.
Data S5: Selected-condition hard-service feasibility result.
Data S6: Proportional water-side augmentation details.
Data S7: Independent RO and water-tank augmentation details.
Data S8: Electrolyzer-feedwater sensitivity results.
Data S9: H2-service profile sensitivity results.
Data S10: Absolute shortage-penalty scaling results with the freshwater/H2 penalty ratio unchanged.
Data S11: Secondary PCC-limit and carbon-price sensitivity results.

Table S1: 25-condition epsilon-optimal RO-capacity ranges.
Table S2: RO-only and proportional water-side augmentation results.
Table S3: Independent RO and water-tank augmentation results.
Table S4: Absolute shortage-penalty scaling results.

Data S1 retains the sign of the Jeju SMP. Grid import price uses SMP/1,422 in USD/kWh, and grid export price is 0.8 times the signed import-price basis.

In legacy result filenames, `full` denotes fully coupled planning, `decoupled` denotes the feedwater-omitting benchmark, and `reevaluated` denotes fixed-capacity re-evaluation with the complete water balance restored.

The existing integrated XLSX workbook is retained for backward compatibility with the earlier public data layer. The v1.1.0 diagnostic additions and revised Supplementary numbering are represented authoritatively by the CSV files listed above.
