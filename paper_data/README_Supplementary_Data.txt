Supplementary data files

Data S1: 8,760-hour demand, renewable availability, SMP, and grid price series.
Data S2: Representative-period selection metrics and ranks.
Data S3: Proportional water-side augmentation results.
Data S4: Independent RO and water-tank augmentation results.
Data S5: PCC-limit and carbon-price sensitivity results.
Data S6: Core 25-condition coupling results.
Data S7: Service-penalty sensitivity results.
Data S8: Electrolyzer feedwater sensitivity results.
Data S9: H2 service-profile sensitivity results.
Table S1: Service-penalty scaling results.
Table S2: Proportional water-side augmentation results.
Table S3: Independent RO and water-tank augmentation results.

Data S1 retains the sign of the Jeju SMP. Grid import price uses SMP/1,422 in USD/kWh, and grid export price is 0.8 times the signed import price.

In the result files, `full` denotes full-coupled planning, `decoupled` denotes the feedwater-omitting sizing benchmark, and `reevaluated` denotes fixed-capacity full-coupled re-evaluation.
